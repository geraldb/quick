Open AI (Compatible) API  - Chat Completions

see <https://platform.openai.com/docs/api-reference/chat>

HTTP JSON API ("RESTful") - Hello, World! Example:

```
curl https://api.openai.com/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -d '{
    "model": "gpt-4.1",
    "messages": [
      { "role":    "user",
        "content": "Hello!"
      }
    ]
  }'
```

note - two parameters required -  model and messages.


or via Google gemini, see <https://ai.google.dev/gemini-api/docs/openai>

```
curl "https://generativelanguage.googleapis.com/v1beta/openai/chat/completions" \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $GEMINI_API_KEY" \
  -d '{
    "model": "gemini-2.0-flash",
    "messages": [
        {"role": "user", 
         "content": "Hello. What is the answer to life, the universe and everything?"}
    ]
    }'
```

What changed?

- `api_key`="GEMINI_API_KEY": free (tier) key available via Google AI Studio sign-up
- `base_url`="https://generativelanguage.googleapis.com/v1beta/openai/": This sends requests to Google's Gemini API instead of OpenAI's.
- `model`="gemini-2.0-flash": Choose a Google ai model
